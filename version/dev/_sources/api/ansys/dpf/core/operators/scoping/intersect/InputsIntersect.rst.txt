





:class:`InputsIntersect`
========================


.. py:class:: ansys.dpf.core.operators.scoping.intersect.InputsIntersect(op: ansys.dpf.core.dpf_operator.Operator)

   Bases: :py:obj:`ansys.dpf.core.inputs._Inputs`


   Intermediate class used to connect user inputs to
   intersect operator.

   .. rubric:: Examples

   >>> from ansys.dpf import core as dpf
   >>> op = dpf.operators.scoping.intersect()
   >>> my_scopingA = dpf.Scoping()
   >>> op.inputs.scopingA.connect(my_scopingA)
   >>> my_scopingB = dpf.Scoping()
   >>> op.inputs.scopingB.connect(my_scopingB)
   >>> my_output_selection = int()
   >>> op.inputs.output_selection.connect(my_output_selection)

.. py:property:: scopingA
   :type: ansys.dpf.core.inputs.Input[ansys.dpf.core.scoping.Scoping | ansys.dpf.core.scopings_container.ScopingsContainer]


   Allows to connect scopingA input to the operator.

   A scopings container is only supported when scopingB is a scopings container.

   :returns: An Input instance for this pin.
   :rtype: input

   .. rubric:: Examples

   >>> from ansys.dpf import core as dpf
   >>> op = dpf.operators.scoping.intersect()
   >>> op.inputs.scopingA.connect(my_scopingA)
   >>> # or
   >>> op.inputs.scopingA(my_scopingA)

.. py:property:: scopingB
   :type: ansys.dpf.core.inputs.Input[ansys.dpf.core.scoping.Scoping | ansys.dpf.core.scopings_container.ScopingsContainer]


   Allows to connect scopingB input to the operator.

   A scopings container is supported only when output_selection is 1 (intersection only).

   :returns: An Input instance for this pin.
   :rtype: input

   .. rubric:: Examples

   >>> from ansys.dpf import core as dpf
   >>> op = dpf.operators.scoping.intersect()
   >>> op.inputs.scopingB.connect(my_scopingB)
   >>> # or
   >>> op.inputs.scopingB(my_scopingB)

.. py:property:: output_selection
   :type: ansys.dpf.core.inputs.Input[int]


   Allows to connect output_selection input to the operator.

   Selects the outputs to compute: 0 for both the intersection and the difference, 1 for the intersection only, 2 for the difference only. Outputs that are not computed are returned as empty scopings. Default is 0. Must be 1 if scopingB is a scopings container.

   :returns: An Input instance for this pin.
   :rtype: input

   .. rubric:: Examples

   >>> from ansys.dpf import core as dpf
   >>> op = dpf.operators.scoping.intersect()
   >>> op.inputs.output_selection.connect(my_output_selection)
   >>> # or
   >>> op.inputs.output_selection(my_output_selection)
